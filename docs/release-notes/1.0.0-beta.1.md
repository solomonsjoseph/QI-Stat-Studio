QI Stat Studio 1.0.0-beta.1 is the first beta. It is a pre-release for testers and is not ready for real patient data.

## Who this is for

Medical residents running a quality-improvement project, and their mentors. A resident describes the project, uploads a data file and a data dictionary, checks the data, runs the analyses, edits the wording and downloads a Word or PDF report. A mentor reviews the results through a link and leaves comments.

## What you can do in this beta

- Run the whole flow with the QI Stat Advisor off. No key is needed.
- Turn the QI Stat Advisor on with your own AI key in Settings. It proposes fixes for data warnings and drafts interpretations. You review and edit everything before it counts.
- Share a read-only mentor link. The mentor can comment, edit their own comments and sign off. Their comments appear in the Word and PDF reports.

## Install

1. Install Python 3.9 or newer and Node.js 20.19 or newer.
2. `git clone https://github.com/solomonsjoseph/QI-Stat-Studio.git`
3. `cd QI-Stat-Studio/qi_stat_studio` and run `make real`.
4. Open `http://127.0.0.1:5173`, register (the first account is the admin) and open Settings to add your AI key, or skip it.

To use this exact version, run `git checkout v1.0.0-beta.1` after cloning.

## Known limitations

- The app does not send email. Copy the mentor link and send it yourself.
- Not HIPAA compliant. Use synthetic or de-identified data only.
- Plain HTTP on your own machine. HTTPS arrives with hosting in beta 2.
- Open clinical decisions are still with the clinical owner, so some wording and defaults may change.
