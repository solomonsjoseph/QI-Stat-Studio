QI Stat Studio 1.0.0-beta.2 is the second beta. It is a pre-release for testers and is not ready for real patient data. It has the same features as beta 1. Every dependency is now at its latest version, and a fresh install works first time.

## What changed

- The patient name detector in the PHI scrubber now loads on a fresh install. In beta 1 a new install could fall back to the pattern-based scrubber only. `preshed` is pinned to 3.0.15, which fixes the tokenizer error that 3.0.14 caused.
- `make real` and `make stub` reinstall the packages when `requirements.txt` or `web/package-lock.json` changed since the last install, so an older environment is brought up to date.
- `make real` sets up everything behind the scenes (Python environment, packages, language model, `.env`, database) and opens the app in your browser.
- Python 3.12 or newer and Node.js 24.15 or newer are now required.
- Text columns with mixed-case group labels are matched correctly under pandas 3.

## Install

1. Install Python 3.12 or newer and Node.js 24.15 or newer.
2. `git clone https://github.com/solomonsjoseph/QI-Stat-Studio.git`
3. `cd QI-Stat-Studio` and run `make real`. The browser opens at `http://127.0.0.1:5173`. On a server with no display, open that address yourself.
4. Register (the first account is the admin) and open Settings to add your AI key, or skip it.
5. To review as a mentor, the resident opens the Download screen and copies the share link.

To use this exact version, run `git checkout v1.0.0-beta.2` after cloning.

## Known limitations

- The app does not send email. Copy the mentor link and send it yourself.
- Not HIPAA compliant. Use synthetic or de-identified data only.
- Plain HTTP on your own machine. HTTPS arrives with hosting.
- Open clinical decisions are still with the clinical owner, so some wording and defaults may change.
