# Contributor documentation

This section is for people who change QI-Stat-Studio. It is never published to
the docs site.

- [Contributing guide](../../CONTRIBUTING.md): branches, commits, and pull requests.
- [Decision records](adr/0000-template.md): copy the template for each final decision.

Plans, research notes, drafts, and AI session notes are never committed. Keep
them in the gitignored `.scratch/` folder at the repository root.
